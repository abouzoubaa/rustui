These browser fonts are copied unchanged from the pinned `cosmic-text` 0.19.0 source under `vendor/cosmic-text-0.19.0/fonts/`. They are registered only by the WebAssembly runtime, where GPUI has no system font database. `NotoSans-LICENSE` covers the regular, Arabic, and Hebrew Noto Sans files. `InterVariable.ttf` and `Inter-LICENSE` provide the Web theme's variable sans face and weight range. `FiraMono-Medium.ttf` and `FiraMono-LICENSE` provide the Web monospace default; only its Medium face is bundled. Native builds continue to use platform fonts.
