# RustUI 0.4.0

- Upgraded to GPUI Kit 0.9.1 and gpui-pre 0.3.12.
- Minimum supported Rust is 1.98.0. Apps using RustUI must use Rust 1.98.0 or newer.
- Rebased the Kit patches while retaining RustUI-tested behavior where upstream changes were partial.
- Preserved disabled-control behavior across the 201-case matrix.
- Updated accessibility for text inputs, grid headers and cells, dialogs, menus, sliders, and calendar controls.
- Kept tracked dialog focus, selection recovery, and native popup placement/teardown coverage on the new APIs.
- Verified Rust and JSON syntax highlighting through the RustUI CodeEditor.
- The 1,000-row update-only median improved to 4.49 ms from 4.59 ms on A2.
- Update plus forced draw measured 8.64 ms, about 0.40 ms slower than A2's 8.24 ms; it remains under the accepted 9.0 ms limit. Stage F tracks winning back the regression.

Add RustUI from the release tag:

```toml
[dependencies]
rustui = { git = "https://github.com/abouzoubaa/rustui", tag = "v0.4.0" }
```
