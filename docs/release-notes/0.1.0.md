# RustUI 0.1.0 release notes

RustUI is a declarative Rust UI framework built on GPUI and GPUI Components. Version 0.1.0 targets macOS; other platforms are planned for later.

After the release is tagged, add the Git dependency:

```toml
rustui = { git = "https://github.com/abouzoubaa/rustui", tag = "v0.1.0" }
```

For best performance, applications should set the same release profile in their own `Cargo.toml`; Cargo profiles are not inherited by dependents:

```toml
[profile.release]
lto = "thin"
codegen-units = 1
```

## Highlights

- Dialog and sheet focus recovery, with accessible validation errors for text, secure, and search fields.
- Editable DataGrid with validation, sorting, keyboard navigation, conflict handling, and accessibility metadata.
- Typed theme tokens, appear and disappear transitions, and Finder file drops.
- Git consumers can build without a `[patch]` section.
- The 1,000-row update and forced-draw test-window median improved from about 11.9 ms to 8.03 ms.

## Known limitations

- The owner must manually verify VoiceOver and the Finder file-drop story before tagging.
- The packaged Playground smoke check is pending before release.
