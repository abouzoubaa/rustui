# RustUI 0.2.0

RustUI 0.2.0 targets native macOS.

## Highlights

- Completed the dependency license/notice inventory; the packaged notice snapshot has no unresolved notice gaps.
- Accessibility fixes for dialog roles, sheet close actions, slider labels and value actions, lists, trees, editable-grid cell-to-header relations, and announced validation errors.
- Disabled-control behavior verified across all controls with GPUI test-window coverage.
- Menu activation, disabled-item accessibility, selection recovery and focus fixes.
- `FileDropTargetView::accept_described` combines file acceptance with an accessible description.
- Deterministic coverage for async task ownership, cancellation, restart and error recovery.
- Live theme-reload coverage for visible updates, stop, invalid-input recovery and owner release.

## Install

```toml
rustui = { git = "https://github.com/abouzoubaa/rustui", tag = "v0.2.0" }
```
