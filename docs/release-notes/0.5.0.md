# RustUI 0.5.0

- GPUI Fast 0.1.14 replaces gpui-pre as RustUI’s macOS backend; GPUI Kit stays at 0.9.1.
- RustUI owns the five macOS Fast source packages, with licenses preserved and changes maintained as approved patches.
- Collection preserves cell state and subscriptions when Fast replays cached rows, and releases cells outside overdraw or removed from the items.
- Apps using RustUI must use Rust 1.98.0 or newer.
- Existing automated accessibility, disabled-control, async, popup, grid, validation and theme-reload coverage remains passing.

Five-run warmed release-profile GPUI test-window medians (milliseconds):

| Workload | Historical gpui-pre | Adopted Fast |
|---|---:|---:|
| 5,000-row scroll | 1.274208 | 0.128041 |
| 10,000-line editor typing | 0.655584 | 0.559000 |
| Idle draw, 60 panels | 0.257917 | 0.016500 |
| 1,000-row update + forced draw | 8.762925 | 5.493033 |

The final measurements include the Collection retention fix; the historical reference was not rerun for this release. The adopted version includes RustUI hardening as well as the backend change; these CPU timings are not native display-frame timings. Method and run medians: `docs/perf/F0-decision.md`.

Known issues: Collection has 1–3 native scroll presentation gaps above 16.7 ms per capture run. Owner native/visual review is still pending for the scrolling comparison and R-1 grid.

Stage B (theme engine) is next.
