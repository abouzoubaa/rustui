# RustUI 0.3.0

- Upgraded to GPUI Kit 0.8.1 and gpui-pre 0.3.10.
- Minimum supported Rust version is 1.98.0. Apps using RustUI must use Rust 1.98.0 or newer.
- Rebased the GPUI patches; six patches were retired because upstream fixed them.
- Updated accessibility behavior for the new editor and table structures, including disabled text inputs and grid header indices and relations.
- Improved tracked dialog focus behavior.
- Added shared local build-cache guidance and CI build caching.
- Recorded a 1,000-row forced-draw median of 8.24 ms.

Add RustUI from the release tag:

```toml
[dependencies]
rustui = { git = "https://github.com/abouzoubaa/rustui", tag = "v0.3.0" }
```
