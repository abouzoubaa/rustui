The revised editor analysis also learns digit shapes from source-validated zero-offset warmup pixels, then decodes gutter pixels without supplying expected IDs. Unrecognized shapes fall back to OCR; full wrong gutter IDs still fail source-position checks. A numeric fragment in the Rust body is not a gutter label.
