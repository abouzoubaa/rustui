# Component catalog

This catalog records both implemented APIs and planned component routes. RustUI uses
its own public API, GPUI for rendering and lifecycle, and GPUI Components for control
behavior where it fits. Allui is prohibited from the dependency graph, copied source,
and public API.

**Current implemented surface:** Status is recorded per component below. This catalog
does not claim that every API or acceptance contract is complete; planned rows remain
proposals, and implemented slices retain their explicit limits.

Modal presentation is represented by the dialog module. Toast belongs to overlays;
Badge belongs to basic components. A virtualized collection must use upstream
virtualization before introducing another row cache. The implemented Button, Text,
HStack/VStack, input, List, Table, Tree, TabView, Breadcrumb, and NavigationStack
stories are registered in RustUI Lab.
Additional components receive a story when their first working contract lands.
